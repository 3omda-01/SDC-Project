HealEdu is a mobile system designed for early ADHD risk detection, continuous monitoring, and adaptive
support for students in educational environments. It features a dual architecture pairing a teacher/educator interface with a
synchronized student profile, enabling individualized data collection and school-centered oversight. The application combines
gamified cognitive tasks targeting inattentive, hyperactive-impulsive, and combined ADHD presentations with behavioral and
physiological monitoring via an optional smartwatch and embedded sensors. By analyzing gameplay patterns, sensor data,
and structured educator feedback over a six-month period, HealEdu dynamically adjusts game difficulty to refine subtype
identification and track cognitive development. All data are stored in encrypted, access-controlled databases with TLSprotected communication and educator-controlled data sharing. The application prioritizes student safety through a soft
color palette, minimal visual stimulation, session time limits, and a low-EMF/offline mode during assessment activities.
HealEdu is positioned as a scalable, ethically designed digital adjunct for early screening and school-centered support — not
a standalone clinical diagnostic
